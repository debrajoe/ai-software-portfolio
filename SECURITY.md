# Security and Privacy

This is a portfolio repository containing sanitized source and synthetic test material.

Do not commit credentials, API keys, tokens, personal conversations, local databases, runtime state, or identity-provider data. Provider integrations must remain disabled until configured through private local files outside source control.

The Council Room project is intended for local development and demonstration. It has not been approved for public hosting, external access, sensitive data, or production use.

If you discover a security issue, do not post credentials or exploit details in a public issue.
