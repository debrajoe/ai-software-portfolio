# Debra Viel Technical Portfolio

This repository presents two projects that reflect my work in AI systems, data, software testing, and technical problem solving.

## Projects

### OLYMPUS Council Room

A local AI-agent collaboration prototype built with Python, FastAPI, SQLite, Keycloak-compatible OIDC authentication, and a browser interface. The project explores role-based AI participation, meeting workflows, owner-controlled access, short-lived tokens, audit events, and structured review boundaries.

[View the Council Room project](projects/council-room)

My contributions include defining requirements and participant workflows, testing authentication and session behavior, documenting security and privacy boundaries, reviewing evidence, and directing iterative development with AI-assisted engineering tools.

### Five Random

A mobile-first random-number application built with React Native, Expo, and TypeScript. It generates five values using secure random bytes and rejection sampling, validates range and uniqueness rules, and stores settings and recent results locally.

[View the Five Random source](projects/five-random)  
[Open the live Five Random application](https://five-random.modestkoi2048.chatgpt.site)
