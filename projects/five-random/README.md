# Five Random

Five Random is a polished, mobile-first random number picker created by Debra Viel. It generates exactly five whole numbers using secure random bytes and unbiased range selection.

## Live project

https://five-random.modestkoi2048.chatgpt.site

The public website works without an account. Settings and the last 20 generated sets are stored locally in the visitor's browser or device.

## Portfolio contents

- `source/` — Expo/React Native TypeScript source and automated tests.
- `docs/TEST_REPORT.md` — completed checks and known limitations.

## Run the source project

1. Install Node.js 20 or newer and enable pnpm with `corepack enable`.
2. Open PowerShell in the `source` folder.
3. Run `pnpm install`.
4. Run `pnpm start` for Expo, or `pnpm web` for a browser preview.

## Privacy

Five Random has no account, ads, analytics, or tracking. Settings and history remain on the device. Results are described as random selections and do not predict lottery outcomes or improve winning odds.
